# Third-party resources

## Motion Primitives

`app/components/AnimatedSelection.tsx` adapts the shared animated-background pattern by ibelick, discovered via the 21st.dev Motion Primitives collection.

- Source: https://github.com/ibelick/motion-primitives/blob/main/components/core/animated-background.tsx
- Collection: https://docs.21st.dev/@ibelick/library/motion-primitives
- Upstream README identifies the project as MIT licensed: https://github.com/ibelick/motion-primitives

## Design guidance

UI UX Pro Max: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill. Used as a design reference for skeuomorphism, touch interaction, responsive reflow, focus visibility, and reduced motion. Its generic branding suggestions do not override this project's design system.

Portrait images and animation are the existing user-supplied portfolio assets.
