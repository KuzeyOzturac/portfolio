# Kuzey Ozturac Portfolio

A responsive single-page portfolio site built with plain HTML, CSS, and JavaScript.

## Files

- `index.html` — site content and layout
- `styles.css` — responsive visual design
- `script.js` — reveal animations and dynamic footer year

## Run locally

Open `index.html` directly in a browser, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy

### GitHub Pages
1. Create a GitHub repository.
2. Upload these files to the repository root.
3. Open **Settings → Pages**.
4. Deploy from the main branch / root.

### Netlify
Drag the project folder into Netlify Drop.

### Vercel
Import the GitHub repository into Vercel. No framework settings are needed.

## Customize

Replace or expand project links inside `index.html` once you have public GitHub repository URLs for each project.
